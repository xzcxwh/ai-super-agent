# 程序员面试准备指南

## 简历写作

### STAR 法则
每个项目经历都应该按照 STAR 法则来写：
- **S**ituation（情境）：当时项目的背景是什么
- **T**ask（任务）：你要完成什么目标
- **A**ction（行动）：你具体做了什么、用了什么技术
- **R**esult（结果）：带来了什么可量化的成果，比如性能提升 30%、日活增加 10 万

### 技术关键词
简历中应该包含与你目标岗位匹配的技术关键词。HR 和 ATS 系统会扫描这些关键词。

## 面试高频问题

### 1. 请介绍一下你做过的最有挑战的项目
回答思路：选一个能展示你技术深度的项目，按照"问题 → 方案 → 实现 → 反思"的结构来回答。

### 2. 你对加班的看法
不要直接说"可以"或"不行"。结合自己的职业规划来说。

### 3. 解释一下 HashMap 的底层原理
这是 Java 面试必问题。回答要点：
- 数组 + 链表 + 红黑树的数据结构
- put 方法的流程：hash → 定位桶 → 链表/红黑树插入 → 扩容判断
- 扩容机制：容量翻倍，重新 hash
- 为什么线程不安全：put 时可能形成环形链表

## 算法准备

### 必刷题目类型
1. 排序算法（快排、归并、堆排）及其变体
2. 二叉树遍历（前中后序、层序遍历）
3. 动态规划（背包问题、最长子序列）
4. 双指针（链表判环、有序数组合并）

### 刷题策略
- 每天 2-3 道，保持手感
- 同一道题尝试多种解法
- 不仅要写出来，还要能讲清楚时间复杂度和空间复杂度

## 面试当天注意事项

1. 提前 15 分钟到达
2. 带上纸质简历和笔
3. 自我介绍控制在 1-2 分钟
4. 遇到不会的问题不要慌，可以说"这个我不太熟悉，但我的理解是..."
5. 面试结束后 24 小时内发感谢邮件
